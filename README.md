# TreePygame

## О проекте

`TreePygame` — мистический survival/defense-прототип вокруг центральной идеи дерева, маны, ловушек, карты и враждебных существ. Проект разбит на игровые подсистемы, поэтому хорошо читается как каркас для более крупной авторской игры.

## Что внутри

- основной игровой цикл вынесен в `game_logic.py`;
- отдельные модули для интерфейса, игрока, карты и ресурсов;
- система маны;
- ловушки и действия ловушек;
- отдельные сущности вроде ворон;
- в папке `mystic_tree_0_1/` лежит ранняя версия проекта.

## Стек и структура

- Python
- `pygame`
- ключевые файлы: `main.py`, `game_logic.py`, `game_interface.py`, `map_generator.py`, `mana.py`, `player.py`, `traps.py`, `traps_actions.py`

## Запуск

```bash
python main.py
```
